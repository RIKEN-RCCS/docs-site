# 内規「「理究」でのデータ等の取扱について」

<div class="rules-meta" markdown>

国立研究開発法人理化学研究所<br>
計算科学研究センター<br>
(2026 年 7 月 6 日制定)

</div>

<div class="rules" markdown>

計算科学研究センター（以下、「センター」という。）は、「理究」（AI for Science スーパーコンピュータ）におけるデータ等について以下のように扱うものとする。

## 1.　「理究」の利用者のファイルについて { #section-1 }

「理究」のアカウントを付与された利用者（以下、「利用者」という。）が、「理究」を利用するためにストレージに保存したプログラム、計算に必要なデータ、及び計算結果（以下、「データ等」という。）について以下のように取り扱うものとする。

<div class="rules-items" markdown>

(1)　センターは、データ等の漏洩、滅失または毀損を防止するため、必要な予防措置を講じ、適正に管理する。

(2)　センターは、「理究」のシステム障害対応や運用改善のための利用状況分析等の場合以外は、データ等にアクセスしない。データ等に記録された内容を分析する必要がある場合は事前にユーザに確認を取ったうえでアクセスするものとする。なお、ゲノム情報等の個人情報が含まれる場合はアクセスしない。

(3)　センターは、データ等のバックアップは取得しない。データ等のバックアップは、利用者が必要に応じて取得するものとする。

(4)　利用者は、データの整理に努め、不要なデータ等を長期にわたり保管しない。概ね保存期間が一年を超えるものは、すみやかにバックアップを取得するか、消去する。

(5)　センターは、「理究」の利用期間が終了した後のログイン猶予期間（1 か月）が経過した後に、データ等をすみやかに消去する。

</div>

## 2.　センターが収集するデータについて { #section-2 }

センターは、「理究」の運用時に以下の情報を収集する。

- **ジョブ情報**

    ジョブ実行履歴などジョブ実行に関する情報。

- **ジョブスクリプト**

    ジョブの実行の際に用いられたジョブスクリプト。

- **性能情報**

    プログラムの性能情報（FLOPS、メモリスループット、消費電力、省電力機構の利用状況、ファイル I/O や GPU 利用のプロファイル等の情報）。

- **翻訳情報**

    プログラムの翻訳情報（使用ライブラリ、コンパイラ、プログラムの種類等の情報）。

- **ファイル情報**

    ストレージ上に生成されたファイル等に関する情報（サイズ、作成日、更新日、ファイルの配置情報等の情報）。

- **ネットワーク情報**

    「理究」の計算ノードやフロントエンドサーバ等から「理究」外部への通信に関する情報（接続先、通信パケットの内容等の情報）

センターは、これらの情報に対し以下のとおり取り扱うものとする。

<div class="rules-items" markdown>

(1)　センターは、これらの情報を利用状況の分析および運用改善の目的に利用し、これ以外の目的では使用しない。

(2)　センターは、次の場合を除いて、収集した情報を第三者に開示しない。

<div class="rules-items" markdown>

①　「理究」の運用改善やヘルプデスク対応等の利用者の利便性向上を目的に、センターが別途定める「理究」の利用促進業務を担う機関と情報共有を行う場合。この場合は、利用促進業務を担う機関に対して、本取扱を遵守させるものとする。

②　「理究」の運用に関する業務委託を行う場合であってかつ運用上必要がある場合。この場合は、当該業務を行う者に対して、本取扱を遵守させるものとする。

③　「理究」の運用改善に資する共同研究を外部機関等と行う場合。この場合は、相手先に対して本取扱を遵守させるものとする。

④　運用改善の取り組みに関する研究発表や利用者の利便性向上に資する情報公開を行う場合。ただし本目的による発表や公開は、利用者の特定ができないように統計的処理または匿名化した情報に限るものとし、研究発表で使用された情報は成果発表後から原則 10 年間保存する。

⑤　法令等による要請がある場合。

⑥　その他、プロジェクト推進主体等からの要請がある場合。

</div>
