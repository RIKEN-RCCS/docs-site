# 誓約書（有償利用）

<div class="rules" markdown>

国立研究開発法人理化学研究所<br>
計算科学研究センター<br>
センター長 松岡 聡 様

「理究」（RIKEN AI for Science 開発用スーパーコンピュータ）（以下「本システム」という。）の利用にあたり、本システムの利用目的である研究課題に参加する利用者（以下「課題参加者」という。）を代表し、下記の誓約事項を遵守すること並びに課題参加者全員に遵守させることを誓約いたします。

<p class="rules-center">記</p>

## （基本方針） { #article-1 }

第１条　課題参加者は、本システムの利用にあたり、科学技術の振興に資する目的で適正に利用するものとし、その実施及び成果の利用が関係法令及び社会通念に照らし妥当であることを保証する。

２　課題参加者は、関係法令並びに国立研究開発法人理化学研究所（以下「研究所」という。）及び計算科学研究センター（以下「センター」という。）が定める本システムの利用規則、その他の規程及び手続を遵守する。

３　課題参加者は、本システムの利用について責任を負うものとし、他の課題参加者に対して本誓約事項を遵守させる義務を負う。

４　課題参加者は、センターが定めるサービスレベル目標等を理解したうえで本システムを利用する。

５　課題参加者は、割り当てられた計算資源を申請した研究課題の目的にのみ利用し、目的外利用を行ってはならない。

## （研究課題及び成果の取扱い） { #article-2 }

第２条　研究課題の内容、成果の公表及び報告等については、センターが別途定める規程に従うものとする。

## （施設及び設備の使用） { #article-3 }

第３条　課題参加者は、センターの施設及び設備を使用する場合には、当該使用に関する規程及び手続を遵守するとともに、センター職員の指示に従うものとする。

## （利用料金） { #article-4 }

第４条　課題参加者は、本システムの利用にあたり、センターが別途定める利用料金を負担し、センターの請求に従い支払うものとする。

２　利用料金の体系、算定方法及び支払条件については、センターが別途定める規程による。

３　センターの施設及び設備を利用した場合において、電気料金その他個別に定める経費が生じたときは、課題参加者はこれを負担する。

## （利用期間） { #article-5 }

第５条　本システムの利用は、センター又はセンターが別途定める機関に所定の申請を行った結果許可された有効期間、センター又はセンターが別途定める機関により付与されたアカウントの有効期間のどちらか短い期間内に限り許される。

２　センターは、本システムの計算資源を継続的により多く提供する努力を行うが、利用者に対し利用期間内に利用可能な計算資源量を保証するものではないことを理解する。

## （データ及び個人情報の取扱い） { #article-6 }

第６条　課題参加者は、本システムにおいて取り扱うデータについて適切に管理する責任を負う。

２　本システムにおいては、利用者データのバックアップは原則として提供されないため、課題参加者は必要に応じて自己の責任でバックアップを取得するものとする。

３　本システムの利用に伴い取得される個人情報及びログ情報は、センターの定める規程に基づき取り扱われることに同意する。

## （知的財産権） { #article-7 }

第７条　本システムの利用により得られた成果に係る知的財産権は、原則として課題参加者又は所属機関に帰属するものとする。ただし、センターの知的貢献が認められる場合には、別途協議のうえ定める。

## （利用環境及びセキュリティ） { #article-8 }

第８条　課題参加者は、アカウントその他本システムの利用に必要な情報を適切に管理し、不正利用の防止に努めるとともに、当該アカウントに基づく行為について責任を負う。

２　課題参加者は、第三者に本システムを利用させてはならない。

３　課題参加者は、法令に違反する行為、又は本システムの運用に支障を与える行為を行ってはならない。

## （利用の停止等） { #article-9 }

第９条　課題参加者が本誓約事項又は関係規程に違反した場合、その他センターが不適切と認めた場合には、センターは本システムの利用の停止又は承認の取消しを行うことができる。

## （損害賠償） { #article-10 }

第 10 条　課題参加者の責に帰すべき事由によりセンターに損害を与えた場合には、課題参加者は当該損害を賠償する責任を負う。

２　本システムの利用に関連して第三者との間で生じた紛争については、課題参加者の責任及び負担において解決する。

## （免責） { #article-11 }

第 11 条　本システムの利用に関連して課題参加者に生じた損害について、研究所及びセンターは一切の責任を負わない。

## （その他） { #article-12 }

第 12 条　本誓約書に定めのない事項については、センターが別途定める規程によるものとする。
