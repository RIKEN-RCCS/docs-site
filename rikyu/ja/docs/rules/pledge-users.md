# 誓約書（利用者向け）

「理究」（RIKEN AI for Science 開発用スーパーコンピュータ）（以下「本システム」という。）のアカウントの取得及び利用にあたり、下記の誓約事項を遵守することを誓約いたします。

<p class="rules-center">記</p>

## （基本方針） { #article-1 }

第１条　利用者は、本システムの利用に関し、科学技術の振興に資する目的で適正に利用するものとし、その利用が関係法令及び社会通念に照らし妥当であることを保証する。

２　利用者は、関係法令並びに国立研究開発法人理化学研究所（以下「研究所」という。）及び計算科学研究センター（以下「センター」という。）が定める RIKEN AI for Science 開発用スーパーコンピュータ利用規則その他の規程を遵守する。

３　利用者は、本システムの利用について責任を負う。

## （利用目的の制限） { #article-2 }

第２条　利用者は、本システムを違法、不正又は有害な目的で利用してはならない。

２　利用者は、利用時点において参加する研究課題が未確定の場合であっても、安全保障輸出管理に関する法令を遵守し、本システムを当該法令により規制される技術の開発又は提供その他該当用途に供してはならない。

## （利用環境） { #article-3 }

第３条　利用者は、を適切に管理し、不正利用の防止に努めるとともに、当該アカウントにアカウント及び認証情報基づくすべての行為について責任を負う。

２　利用者は、第三者に本システムを利用させてはならない。

## （情報の提供） { #article-4 }

第４条　センターは、本システムの適正な運用のため必要がある場合、利用者に対し利用状況に関する情報の提供を求めることができる。

２　利用者は、前項の求めがあった場合、これに応じなければならない。

## （違反） { #article-5 }

第５条　利用者が本誓約又は関係規程に違反した場合、又は虚偽の申告が判明した場合、センターはアカウントの利用停止その他必要な措置を講ずることができる。

## （損害賠償） { #article-6 }

第６条　利用者は、その責に帰すべき事由によりセンター又は第三者に損害を与えた場合、これを賠償する責任を負う。

## （免責） { #article-7 }

第７条　本システムの利用に関連して利用者に生じたいかなる損害についても、研究所及びセンターは責任を負わない。

## （その他） { #article-8 }

第８条　本誓約書に定めのない事項については、センターが別途定める規程による。
