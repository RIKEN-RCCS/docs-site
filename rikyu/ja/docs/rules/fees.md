# 科学研究基盤モデル開発プログラムにおける研究設備の利用料の取扱いについて

<div class="rules-meta" markdown>

制定日 令和8年6月12日

</div>

<div class="rules" markdown>

## 1 目的 { #section-1 }

この内規は、科学研究基盤モデル開発プログラムにおける研究設備の利用者が費用負担する額（以下「利用料」という。）について、必要な事項を定めることを目的とする。

## 2 利用料の算出 { #section-2 }

研究設備の利用単価は、研究設備の利用により発生する基礎的経費（消耗品費、人件費、設備保守費、光熱水費等）、知的貢献費、管理費を基に算出する。

## 3 利用単価 { #section-3 }

利用単価は、別表に定める通りとする。

## 4 手続き { #section-4 }

利用者は所定の方法で利用申請し、通知された利用料を負担する。

## 5 管理 { #section-5 }

研究設備利用に係る管理は、計算科学研究センター 運用技術部門及び計算科学研究推進部が行う。
