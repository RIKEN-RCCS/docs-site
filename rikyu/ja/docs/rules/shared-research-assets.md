# 内規「「理究」での共有研究資産の取扱について」

<div class="rules-meta" markdown>

国立研究開発法人理化学研究所<br>
計算科学研究センター<br>
(2026 年 7 月 6 日制定)

</div>

<div class="rules" markdown>

計算科学研究センター（以下、「センター」という。）は、「理究」（RIKEN AI for Science 開発用スーパーコンピュータ）において、利用者の研究成果などの共有に関し以下のように取り扱う。

## 第１条（目的） { #article-1 }

本内規は、「理究」を利用して創出された研究成果の再利用及び流通を促進し、AI for Science 研究の発展に資することを目的として、共有研究資産の取扱いについて定める。

## 第２条（共有研究資産） { #article-2 }

共有研究資産とは、利用者が「理究」を利用して作成したデータセット、ソフトウェア、学習済みモデル、推論サービス、評価結果、ワークフローその他センターが認める成果物をいう。

## 第３条（登録） { #article-3 }

利用者は、自ら権限を有する共有研究資産を任意に登録することができる。

## 第４条（公開区分） { #article-4 }

共有研究資産は次の区分で登録できる。

<div class="rules-items" markdown>

(1)　非公開

(2)　共同研究者限定共有

(3)　「理究」利用者限定共有

(4)　一般公開

</div>

## 第５条（利用条件） { #article-5 }

共有研究資産の利用条件は登録者が定めるものとする。

## 第６条（権利帰属） { #article-6 }

共有研究資産に関する知的財産権その他の権利は、別段の定めがある場合を除き登録者に帰属する。

## 第７条（免責） { #article-7 }

研究所及びセンターは、共有研究資産の内容、品質、安全性、有効性及び第三者権利の非侵害について保証しない。
