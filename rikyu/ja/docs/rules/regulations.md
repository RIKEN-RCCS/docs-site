# 「理究」利用規則

<div class="rules-meta" markdown>

国立研究開発法人理化学研究所<br>
計算科学研究センター<br>
(令和８年７月６日制定)

</div>

<div class="rules" markdown>

## (趣旨) { #article-1 }

第１条　この規則は、国立研究開発法人理化学研究所（以下「研究所」という。）計算科学研究センター（以下「センター」という。）が管理・運用する「理究」（AI for Science 開発用スーパーコンピュータ）の利用について、必要な事項を定める。

## (利用目的) { #article-2 }

第２条　「理究」の利用は、科学技術の振興に寄与するともに、AI for Science に係る研究開発、研究成果の再利用及び共有並びに研究コミュニティの形成に資するものでなければならない。

## (利用資格) { #article-3 }

第３条　「理究」を利用し又は利用しようとする者（以下「利用者という。）は、次の各号に掲げる者とする。

<div class="rules-items" markdown>

（１）センターが別途定める機関もしくは、センターによって選定・確認された研究課題を行う者

（２）「理究」の安定運用のためのシステム調整、利用者の利用支援のための研究開発、データ科学・AI 分野を含めた幅広い利用者の利用に資する高度化研究・利用支援、利用者の拡大、計算科学の先導的研究開発及びセンターが別途定める機関の利用支援課題等を行うために、計算科学研究センター長及びセンター長が指名した者（以下「センター長」という。）が利用を認めた者

</div>

## （サービスの提供） { #article-4 }

第４条　センターは、利用者に対し、次の各号に掲げるサービスを提供し、利用者は、これを利用することができる。

<div class="rules-items" markdown>

（１）「理究」の計算資源

（２）センターが用意したソフトウェア

（３）「理究」の利用に係る支援

（４）その他センターが追加したサービス

</div>

２　センターは、サービスの内容の一部又は全部について、随時変更できる。ただし、重要な変更を行う場合には、利用者に通知するものとする。

## (利用者登録及び利用期間) { #article-5 }

第５条　利用者は「理究」の利用に際し、センター又はセンターが別途定める機関に所定の申請を行うものとする。

２　センター長は前項の申請を受け付け、利用資格等を確認できたときは、「理究」を利用するためのアカウントを付与する。ただし、以下のいずれかに該当する場合には、アカウントを付与しないことがある。

<div class="rules-items" markdown>

（１）誓約書に違反した場合、または、同意しなかった場合

（２）安全保障輸出管理に係る審査結果に基づき、利用が認められない場合

（３）犯罪その他不当な目的による利用が疑われる場合

（４）過去に不正行為や不適切行為などが認められ、「理究」の利用に関して懸念がある場合

（５）科学技術に資する活動以外の目的での利用が疑われる場合

（６）前各号のほか、利用が適切でないと認められる場合

</div>

３　センター又はセンターが別途定める機関は前項のアカウントの付与を受け、利用者に利用登録の完了を通知するものとする。

４　アカウントの有効期限は、センター又はセンターが別途定める機関が定める期間とする。

５　利用者は、アカウントの有効期間内において第１項の申請内容に変更が生じたときは、速やかにセンター又はセンターが別途定める機関に届け出なければならない。

## （利用者の義務） { #article-6 }

第６条　利用者は、「理究」の利用にあたり本規則を遵守しなければならない。

２　利用者は、安全保障輸出管理に関する法令等の「理究」の利用に適用される関係法令等に違反していないことを誓約するとともに、「理究」の利用について責任を負わなければならない。

３　利用者は、「理究」を利用した際の成果等の帰属及び利用成果の公表・報告について、研究所、センター又はセンターが別途定める機関が定めるところに従わなくてはならない。

４　利用者は、アカウント等、「理究」の利用に必要な情報を適切に管理し、不正利用の防止に努め、自らのアカウントに基づき生じるあらゆる活動について責任を負うものとし、研究所は利用者のアカウントへの不正アクセスについて責任を負わないものとする。

５　利用者は、第５条第１項の規定により申請した研究課題等以外のために「理究」を利用してはならない。また、利用者本人以外の第三者に「理究」を利用させてはならない。

６　利用者は、研究課題の申請時にデータマネジメントプランを策定するとともに、プランに沿ったデータ公開に努めなければならない。また、「理究」に保存するデータは、一時的な保存であることを踏まえ整理に務めるとともにセンターからの削除要請などに協力すること。

７　利用者は、「理究」をインターネット上の IT システムとして適正に利用しなければならない。特に違法、有害なコンテンツを扱ってはならない。また、セキュリティ違反をもたらす行為を行ってはならない。さらに、ネットワークの不正使用を行ってはならない。

## （研究成果物の共有） { #article-7 }

第７条　利用者は、研究成果の再現性向上、研究開発の加速及び研究コミュニティの発展に資するため、法令、契約その他の制約に反しない範囲において、「理究」を利用して作成したデータ、ソフトウェア、学習済みモデル、評価結果その他の成果物を共有又は公開するよう努めるものとする。

２　利用者は、前項の成果物について、研究所又はセンターが提供する共有基盤を利用し、他の利用者による研究目的での利用を認めることができる。

３　前項の共有の範囲及び利用条件は、当該成果物を提供する利用者が定めるものとする。

４　研究所は、共有された成果物の内容、品質、安全性及び第三者権利の非侵害について保証しない。

## （利用料金） { #article-8 }

第８条　利用者は、「理究」を利用する場合、利用区分に応じて別に定める利用料金をセンターに支払わなければならない。

２　利用者は、センターの持込サーバー室等の施設、設備等を使用した場合に、個別に定める経費が生じたときは、その経費を支払わなければならない。

## （利用の制限等） { #article-9 }

第９条　センターは、別に定めるところにより、利用者が本規則を遵守しているか監視することができ、「理究」の運用に支障をきたす恐れのある場合、利用者に対して、利用方法の改善を指示することができる。また、利用者はその指示に協力しなければならない。

２　利用者が前項に従わない場合、又は次の各号の一に該当したときは、センターは「理究」の利用承認の取り消し、又はその利用を停止させることができる。

<div class="rules-items" markdown>

（１）本規則を遵守しなかったとき

（２）「理究」の利用にあたり、利用資格を喪失したとき

（３）センター又はセンターが別途定める機関に提出する書類に虚偽の記載があることが判明したとき

（４）アカウントの有効期限を過ぎたとき

（５）利用料金を支払わないとき

（６）第５条第２項各号の事由に該当することが判明したとき

（７）その他、センターが「理究」の運用に支障をきたすと判断するとき

</div>

３　センターは、「理究」の安定運用を目的に、次の各号に掲げる措置を予告なしに実施できるものとする。

<div class="rules-items" markdown>

（１）利用者のアカウントが第三者に利用されていると疑われる場合に、アカウントを一時停止

（２）「理究」に過負荷を与える恐れがある操作が行われていると疑われる場合に、該当操作を一時停止、又は停止

（３）その他、「理究」の安定運用を維持するための処置

</div>

## （「理究」の停止） { #article-10 }

第１０条　センターは、やむを得ない場合について、利用者への予告なしに「理究」の運用を停止することができる。

## (研究所の免責) { #article-11 }

第１１条　「理究」の利用において、利用者が損害を被った場合、又は利用者がその他「理究」に関連して損害を被った場合、又は利用者が第三者に損害を与えた場合について、研究所は一切の責任及び負担を負わない。

２　理由の如何を問わず、予定していた利用時間が減少、又は「理究」を利用できなかったことに伴い利用者に被害が発生した場合において、研究所は一切の責任及び負担を負わない。

３　安全保障輸出管理の対象となる、利用者が行う技術の提供については、利用者が責任をもって管理することとし、研究所は、当該規制への違反等に関しては、一切の責任を負わない。

## (その他) { #article-12 }

第１２条　この規則に定めるもののほか、「理究」の利用に関し必要な事項は、センターが別に定める。

## 附則 { #supplementary }

この規則は、令和８年７月６日から施行する。

</div>
